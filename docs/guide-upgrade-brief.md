# 초기 가이드 글 보강 작업 지시서 (2026-11-04)

초기 23편(2026-10-12~18 발행) 중 한 편을 **현재 형식으로 재편**하고 **수치를 최신화**하는 작업이다. 본보기는 보강이 끝난 `src/content/guide/ltv-dsr-dti.md`이고, 형식 규칙은 `docs/guide-writing.md`다. 둘을 먼저 읽는다.

## 해야 할 것
1. 지정된 파일 한 개만 고친다. 다른 파일은 만들지도 고치지도 않는다. git 명령(add/commit/push)은 하지 않는다. 빌드도 돌리지 않는다(운영자가 모아서 돌린다).
2. 구조를 재편한다.
   - 첫 문단(제목 없이 2~3문장) → `## 한눈에 보기`(`| 항목 | 내용 |` 2열 3~5줄, 결론 값 **굵게**) → 소제목 5~8개(결론형) → 마지막 `## 정리`(`| 핵심 | 내용 |` 3줄 + 쏙집 기능 링크 한 문장).
   - 병렬 항목 3개 이상은 표. 글당 표 5~9개. 열은 3개 이하 권장, 4열은 꼭 필요할 때만, 5열 이상 금지.
   - **표 머리글은 짧게(한 칸 8자 안팎)**. 머리글은 줄바꿈이 안 되므로 길면 폰에서 표가 옆으로 넘친다. 긴 설명은 표 바로 위 문장(캡션 역할)에 쓴다.
   - 정의는 `>` 한 줄(글당 1~2개). 번호 목록은 순서 있는 행동에만.
   - 분량은 공백 제외 6,000~9,000자 정도(기존 글의 약 2배). 늘리기 위해 중복하지 말고, 독자가 다음에 물을 질문(예외·경계 사례·확인 방법·절차)을 표로 채운다.
   - 기존 글의 좋은 설명과 예시는 살린다. 제목(`title`)과 slug는 바꾸지 않는다. `description`은 다듬어도 된다.
3. 수치를 최신화한다.
   - 대출·세금 수치는 `data/rules/v2026-11-09.json`(2026-11-09 시행분, 그 전까지는 `v2026-10-15.json`이 시행중 — 두 파일은 보금자리론 금리만 다르다)과 **반드시 일치**시킨다. 보금자리론 금리를 다루면 "11월 8일까지 신청분 종전 금리 / 11월 9일 신청분부터 +0.10%p"를 함께 적는다.
   - 규칙표에 없는 수치는 공식 출처(국세청·국토교통부·주택도시기금·한국주택금융공사·법제처·한국부동산원·금융위원회·정책브리핑 korea.kr·공공기관 보도자료)에서 WebSearch/WebFetch로 확인한다. 민간 사이트·블로그는 출처로 쓰지 않는다. 언론 기사는 공식 발표를 인용한 것만 보조 출처로 쓸 수 있다.
   - **확인되지 않은 새 수치는 쓰지 않는다.** 기존 글의 수치가 확인되지 않으면 그대로 두되 보고서에 "미확인"으로 적는다. 바뀐 것이 확인되면 고치고 시행일을 적는다.
   - 쏙집 사이트 수치(지역·단지·건수)가 필요하면 `data/index/summary.json`(기준일 `asOf`)에서 읽고 기준일을 같이 쓴다. 없는 숫자를 지어내지 않는다.
   - 머리말 `asOf`와 `updatedAt`을 `"2026-11-04"`로 바꾼다. `publishAt`·`published`·`category`·`cta`·`situation`·`facts`는 그대로 둔다. `related`는 실제로 존재하는 slug 2~3개(`ls src/content/guide/`로 확인). `sources`에는 확인에 쓴 공식 URL을 추가한다(기존 것은 지우지 않는다).
4. 문장 규칙(`docs/guide-writing.md` 3절)을 지킨다: 존댓말, 판단·추천 금지, 가격 전망 금지, 모든 숫자에 기준·출처, 시행일 표기, 머니프리덤·korea-rich.kr 언급 금지, 없는 페이지로 링크 금지(본문 링크는 `/calc/ /find/ /area/ /ref/ /compare/ /guide/<존재하는 slug>/`만).

## 보고서(작업 끝에 답으로 돌려줄 것)
- 구조: 표 개수, 소제목 목록, 공백 제외 글자 수(`sed '1,/^---$/{/^---$/!d}' 파일 | sed 1d | tr -d ' \n' | wc -m`).
- 수치 변경 로그: 고친 수치마다 `기존 → 변경, 근거 URL, 시행일`. 고친 것이 없으면 "수치 변경 없음".
- 미확인·의심 항목: 확인하지 못한 수치, 제도가 바뀌었을 가능성이 있어 운영자가 봐야 할 것.
- 표 머리글이 8자를 넘는 칸이 있으면 적는다.
