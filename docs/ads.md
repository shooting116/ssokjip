# 광고 운영 기록 (애드센스)

애드센스는 2026-11-26에 승인됐다. 이 문서는 광고를 넣고 빼면서 확인한 것과 다시 켤 때 할 일을 적어 둔다.

## 지금 상태 (2026-11-27 13시대 기준)

- **수동 광고: 끔.** `src/lib/ads.ts`의 `MANUAL_ADS = false`. 코드는 그대로 남아 있고, 페이지에는 광고 단위가 들어가지 않는다.
  미리 잡아 둔 자리는 예전처럼 빈 칸(`.ad-slot`)만 남고, 상단 띠 자리와 가이드 본문 중간 자리는 그리지 않는다.
- **자동광고(애드센스 화면에서 운영자가 직접 설정):** 인페이지 배너는 끔. 오버레이(앵커·전면·사이드 레일)와 의도 기반 형식은 켬.
  이 줄은 11-27에 들은 내용이며, 실제 설정은 애드센스에서 확인한다.
- 그래서 지금은 본문 안에 들어가는 광고가 없다.

## 끈 이유

2026-11-27 운영자 폰에서 가이드 본문 중간 광고가 한 화면 가까이(높이 약 680px) 길게 나왔다.
애드센스가 준 반응형 코드(`data-ad-format="auto"` + `data-full-width-responsive="true"`)는 폰에서 화면 폭으로 넓히고 높이는 구글이 정한다.
확인용 브라우저에서는 370px 안팎으로만 나와 미리 알지 못했다.

## 다시 켤 때

1. **먼저 폰에서의 높이를 제한한다.** 제안했던 안(아직 승인 전): 본문 안 광고(중간·하단·목록 중간·계산기 결과)를
   상단 띠와 같은 방식으로 높이 280px에 고정한다. 반응형 속성을 빼고 페이지 안 `<style>`로 크기를 준다.
   애드센스 도움말 "How to modify your responsive ad code"의 방식이며, 외부 스타일시트로 크기를 주는 것은 공식 지원이 아니다.
2. `MANUAL_ADS = true`로 바꾸고 빌드한다.
3. 폰 폭 시안을 운영자에게 먼저 보여주고, 승인 후 올린다.
4. 올린 뒤 실제 광고가 어떻게 나오는지는 운영자 폰 화면으로 확인한다(아래 '확인할 때 주의').

## 수동 광고 구성

광고 단위 3개(번호는 `src/lib/ads.ts`). 게시자 ID와 단위 번호는 페이지 소스에 드러나는 공개값이다.

| 단위 이름(애드센스) | 코드의 이름 | 쓰는 자리 |
|---|---|---|
| 쏙집(반응형 결과아래) | `result` | 계산기 결과: "매달 약 ○○만 원" 카드 아래 |
| 쏙집(반응형 리스트 중간) | `mid` | 구 상세·시도 레퍼런스·단지 상세의 목록 중간, 가이드 본문 중간, 상단 띠(전용 단위 전까지 같이 씀) |
| 쏙집(반응형 리스트 하단) | `bottom` | 가이드 글·노선 상세·노선 목록·단지 상세의 맨 아래 |

- **상단 띠**(`pos="top"`): 제목 바로 아래, 높이 고정(폰 100px · PC 90px). 가이드 글·지역별 목록·구 상세(단지 찾기 버튼 아래)·
  노선 상세·노선 목록·시도 레퍼런스·단지 상세. 계산기·홈·집 찾기에는 넣지 않는다.
  '상단' 단위를 따로 만들면 `AD_TOP_SLOT`의 번호만 바꾼다.
- **가이드 본문 중간**(`src/lib/ui/guide-ads.ts`): 본문 4,000자(공백 제외) 이상이면 2개(1/3 · 2/3 지점), 미만이면 1개(1/2 지점).
  소제목(h2) 바로 위에만 둔다. 2026-11-27 기준 64편 중 2개 49편 · 1개 15편.
- **노선 상세의 목록 사이에는 넣지 않는다.** 노선이 끊겨 보인다는 운영자 의견으로 뺐다.
- 광고가 표시될 때만 여백과 작은 '광고' 표시가 붙고, 채워지지 않으면 자리째 숨긴다(`global.css`의 `.ad-slot`).
  광고 스크립트를 불러오지 못하면(광고 차단 등) `html.noads`로 모든 광고 자리를 숨긴다.

## 확인한 사실

- **광고 스크립트는 사이트 스타일시트보다 먼저 페이지 폭을 잰다.** 그 순간 본문 폭이 정해져 있지 않으면 PC에서 자동광고 맨 위 광고가
  1,200px로 잡혀 본문 밖으로 나간다. 그래서 `Base.astro`의 `<head>`에, 광고 스크립트보다 앞에 `.wrap` 폭 규칙 한 줄을 인라인으로 둔다.
  스타일시트에만 두거나 `var(--max)`로 쓰면 효과가 없다(2026-11-27 실제 사이트 시험).
- **`data-ad-status`는 세 가지다.** `filled`(광고), `unfilled`(없음), `unfill-optimized`(광고가 없을 때 구글이 대신 넣는 '자세히 알아보기' 묶음).
- **반응형 코드의 요청 크기:** PC는 자리 폭 × 280(본문 폭 608), 폰은 화면 폭 × 390으로 요청하지만 실제 광고 높이는 더 길 수 있다.
- **자동광고 인페이지 배너**는 카드 안·요약 숫자 사이처럼 열 때마다 다른 곳에 들어가고, 카드 안에서는 안쪽 여백만큼 밀려 카드 밖으로 나갔다.

## 확인할 때 주의

- 광고가 뜨는 상태로 사이트를 자동으로 여러 번 여는 일은 줄인다. 구글은 이런 접속을 걸러내지만 새 계정에서는 조심한다.
  화면 배치는 광고를 막은 상태로 확인하고, 광고를 켠 확인은 한두 번으로 끝낸다.
- 확인용 브라우저에는 실제 광고 대신 '자세히 알아보기' 묶음만 뜨는 일이 많다. 실제 광고의 크기·내용은 운영자 화면으로 본다.
- 로컬 미리보기에서는 광고가 뜨지 않는다. 시안은 광고 자리에 예시 상자를 채워서 만든다.
